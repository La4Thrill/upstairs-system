# 报告插图与复现办法

本目录存放课程设计报告中用到的三张插图，均由 `tools/figures/` 下的脚本绘制（不依赖
matplotlib，只用 Pillow，中文字体取系统 simhei / simsun）。

| 文件 | 报告中的编号 | 内容 | 生成脚本 |
|---|---|---|---|
| `fig1_arch.png` | 图 1 | 系统总体架构图（感知层 / 端侧处理层 / 传输层 / 平台与应用层） | `make_fig1.py` |
| `fig2_flow.png` | 图 2 | 台阶检测与楼层计数算法流程图 | `make_fig2.py` |
| `fig3_wave.png` | 图 3 | 真机连续上楼时的实测波形（52 秒，三个面板） | `make_fig3_wave.py` |

## 复现命令

在仓库根目录执行（需要 Pillow）：

```bash
# 图 1、图 2：结构图，不依赖数据
python tools/figures/make_fig1.py
python tools/figures/make_fig2.py

# 图 3：读一份六轴数据文件，输出到 docs/img/fig3_wave.png
python tools/figures/make_fig3_wave.py <数据文件.txt>
```

`make_fig3_wave.py` 不带参数时默认读 `testdata/walk_real.txt`；若文件短于 52 秒，
会自动把窗口挪到动态加速度最大的那一段。

报告中那张图 3 用的是 2026-11-05 的真机实采数据（400 秒、连续上楼），
窗口取 268～320 秒，检出 59 级台阶、两次到层事件：

```bash
python tools/figures/make_fig3_wave.py path/to/STM32-01_raw_20261105_140731.txt
# → 窗口内台阶: 59  到层事件: [(289.7, 2), (300.0, 3)]
```

## 图中三个面板的含义

1. **加速度模长 `|a|` 与重力基线**：蓝线是 `|a|`，灰线是一阶低通（α=0.03 @50 Hz）
   估计出的重力分量。上楼时 `|a|` 在 0.7～1.5 g 之间周期性起伏，基线稳定在 0.93 g。
2. **角速度模长 `|ω|`**：只用于观察躯干转动，**不参与台阶与楼层判定**。
3. **动态加速度 `dyn = |a| − 基线`**：台阶判定的唯一依据。超过 0.18 g 的峰计为
   一级台阶（绿色三角），累计满 22 级输出整层事件（橙色竖线）。

## 关于原始数据里的零值样本

`|a|` 曲线上每隔约 1.02 秒会出现一个掉到零的尖刺，是**加速度寄存器偶发读取失败**
（同一次读取中陀螺数据正常）。脚本在作图时用前一有效值保持，否则会在 `dyn` 上
产生约 −0.9 g 的虚假负落差并误触发迟滞回弹，使台阶数偏高。详见报告 4.5 节表 8 第 16 项。
